# Welcome to Stars Emulator Project!

Out goal is to create an **Android Emulator** with a super simple UI for running **every** .apk file on Windows and MacOS.
SEP is inspired by **PlayCover** so we want to keep everything as simple as possible for user. You only need to download the .apk file, import it into the emulator and then start using it without any configuration else.
