Graphical User Interface

1. Introduction​

The Graphic User Interface (GUI) is an important part of the emulator. It is responsible for providing a user-friendly interface for users to interact with the emulator. The GUI is designed to be simple and intuitive, allowing users to easily import .apk files, start and stop the emulator, and manage their applications.

2. Requirements​

We take inspiration from PlayCover and try to make the GUI as simple as possible (PlayCover screenshot above). It must comply with the following requirements:

  1. Ease of using: Clean and easy-to-use interface that allows users to quickly import .apk files and start using them without any lag or delay.
  2. Lightweight: The GUI is designed to be responsive and lightweight, ensuring that it does not consume too many system resources while running.
  3. Cross platforms consistency: The GUI should be able to run on both Windows and MacOS, providing a consistent experience across platforms.
  4. Multiple instance ability: The GUI should be able to handle multiple instances of the emulator, allowing users to run multiple applications simultaneously.
  5. Full features: The GUI should provide basic features such as starting and stopping the emulator, managing applications, and viewing logs.
  6. Error handling ability: The GUI should be able to handle errors gracefully, providing users with clear error messages and options for troubleshooting.
  7. Emulator information: The GUI should be able to provide users with basic information about the emulator, such as the version number, system requirements, and any known issues.
  8. Application information: The GUI should be able to provide users with basic information about the application, such as the version number, permissions, and any known issues.
  9. Resources usage: GUI should be able to provide users with basic information about the system, such as the CPU, RAM, and storage usage.
